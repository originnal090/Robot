## 使用与复现

GUI 勾选“使用端侧模型 / 实验版本”，选择：

`artifacts/edge-route-20260914/route-balanced-v1/profile.json`

结束旧会话后重新开始。JSON 固定的是与 `hybrid-v1-fast` 相同的检测配置；
寻路、速度、到达条件仍由当前项目配置和另一个任务的实现控制。
选择 NPZ 会走原全图 SVM，若要复现本报告混合结果，应选 JSON。

```sh
python -m hcirobot --config config.toml --edge-model artifacts/edge-route-20260914/route-balanced-v1/profile.json --check-config
python tools/benchmark_edge_detector.py --frames artifacts/captures/capture-20260914-213403 --edge-model artifacts/edge-route-20260914/route-balanced-v1/profile.json --out artifacts/orangepi-route-balanced-run1.json --limit 99 --threads 1 --fps 10
```

训练入口：`tools/train_route_models.py`；修正版加 `--balanced-only`。
回放入口：`tools/eval_route_models.py`；最终对照加 `--balanced-study`。
审计入口：`tools/audit_route_models.py`。这些脚本拒绝覆盖已存在的输出；复现实验应在新目录/
副本中运行或改用新的版本名。训练依赖原采集 PNG，模型包不包含整套原图。

产物都在 `artifacts/edge-route-20260914/`：

- `manifest.json`：三个新版本的权重/配置/哈希清单。
- `comparison/`：初始四版全量回放；`comparison-balanced/`：修正版对照。
- `audit.json`：训练/测试查重、策略参数一致性、旧背景诊断。
- `diagnostics/`：原版、增强版、修正版对照，白框为标注、绿框为预测。
- 各模型目录的 `report.json`：训练统计、求解器状态、增强来源、单图评估。
- `route-models.zip`：三个新模型、配置、标注、报告和识别相关代码快照。

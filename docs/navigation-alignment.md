# 寻球对齐过冲修正（2026-09-14）

保留 `normal_then_slow` 为默认策略。远处常速前进，近处降到慢速；
前进时长仍按球的半径比在 1.5 秒与 0.5 秒之间缩短。
这次修改控制策略，没有训练或改写任何识别模型。

## 修正的控制问题

1. 原先在 `sense` 阶段也发送控制器算出的运动指令。所谓“识别窗口”没有保持静止，
   最长 0.7 秒识别窗口还会接上 1.5 秒盲走窗口，转向可能连续请求约 2.2 秒。
   现在 `sense` 只更新下一步意图并发送停止；只有 `walk` 阶段执行缓存意图。
2. 转向、搜索和可选横移使用独立请求窗口，时长不再由前进距离决定。
   根据机器人按完整动作步执行的特点，已删除按偏差插值时长、跨侧减半时长的逻辑。
   小偏差（小于 `turn_full_error`）使用小步档；连续修正出现跨侧后锁定小步档，
   直到重新确认对齐或重新搜索。改变的是实际动作组，而不是试图执行半步。
   新版默认用 STEP_V1 执行一次动作组，收到完成回执后才经过 `settle` 再识别。
   只有显式关闭单步时，才使用小步 0.18 秒、普通档 0.45 秒的旧请求窗口。
3. 在 `ALIGNING` 内首次进入 ±0.08 区间就停止，静止确认连续 3 帧。
   缺失帧会中断确认，不再用最低档转向把已对准的球推出去。
4. 已进入 `APPROACHING` 后，±0.14 内保持直行，真正使用进入/退出阈值的滞回，
   避免 0.08–0.14 区间的轻微晃动反复触发修正。
5. 对齐/到达确认期间若下一步是停止，继续识别，不浪费一个盲走周期重复停止。
   手动接管、解除自主和避障都会取消缓存动作，恢复时先稳定、重新识别。
6. GUI 热更新保留没有在界面中编辑的控制参数，避免重置模式、脉冲时长和减速阈值。

## 配置与动作选择

在 `[controller]` 内使用：

```toml
approach_mode = "normal_then_slow"
single_step_turns = true
step_timeout_seconds = 10.0
turn_seconds_near = 0.18
turn_seconds_far = 0.45
turn_full_error = 0.45
near_lateral_enabled = false
near_lateral_max_error = 0.25
near_lateral_speed = 0.30
```

`near` / `far` 两个转向时长参数仅用于关闭单步模式后的兼容路径，不表示球的距离。
`turn_full_error` 表示可以使用普通转向档的偏差阈值；跨侧后则继续使用小步档。
机器人端把转向量映射到动作组：同一档位内降低 steer 并不会连续降低角速度。
`turn_left_small_step` / `turn_right_small_step` 才是细调转角的动作基础。
短窗口仅限制持续请求同一动作的时间，不能保证打断已经开始的动作组；
实际最小转角、停止后的动作余量、网络延迟和帧率仍需要真机确认。
如果最短脉冲仍跨过整个对齐区，应优先检查 `turn_*_small_step` 的真实步幅和
`settle_seconds` 是否覆盖收脚过程，不能无限减小 steer 或请求时长来替代动作标定。

**新版服务已实现单次动作及完成回执。** 默认“执行一次 → 收到完成 → 稳定观察”，
包含序号去重、取消、心跳与超时。需要同步更新机器人端服务；仅旧接口兼容模式仍无法保证一步。
实现与部署说明见 [single-step-protocol.md](single-step-protocol.md)。代码已更新，尚未远程部署。

横移仅在主动打开开关、使用间歇策略、半径比达到 `slow_radius_ratio`、
且偏差不超过 `near_lateral_max_error` 时替代转向。每次只横移、不同时转向或前进，
同样支持单次动作和完成回执；右侧球对应向右横移。较远或偏差较大时仍转身。
它适合已经朝向目标的近距离位置微调，默认关闭是因为本段记录没有横移效果证据。
运行事件用 `output_lateral` 记录实际横移输出。

末段低头观察可能有帮助，但目前对外的 `nod` 会低头、抬头、再回正，不能保持观察角度。
直接循环点头会破坏稳定识别，因此本次未接入。后续应先提供可保持俯仰角的接口，
验证近处球的位置、底边裁剪与到达阈值后再接入。

## 验证

横移条件及遥测、识别期停止输出、手动/避障/重新启用后的旧动作取消。
动作映射测试验证跨侧后的指令实际映射到机器人端的 `turn_*_small_step` 动作组。
单次执行的网络与控制循环测试见 `tests/test_single_step.py` 和 `tests/test_step_runtime.py`。

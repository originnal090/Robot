# YOLO11n 红球模型迭代 v3（2026-09-17）

这里的 v3 是项目模型迭代号，网络架构仍为 YOLO11n。这样可继续使用现有
YOLO11 解码器、ONNX 导出和 Ascend 310B1 的 OM 转换链路。

## 数据与划分

- TonyPi：160 张人工标注，123 正 / 37 负；原有 train/test 划分保持不变。
- iPhone 7：原始 1486 张、4 个独立 session；每 5 帧时间抽样并始终保留末帧。
- iPhone 训练：前三个 session，经 v1 教师框、置信度和框内高饱和红色比例联合过滤，
  得到 202 正 / 12 负；20 张不确定帧不参与训练。
- iPhone 留出：完整的 `session-20260916-140239-5E17C5` 不参与训练。56 张可靠正样本
  用于检查召回和框一致性；低置信帧中含运动模糊的真球，因此不把它们自动标成负样本。
- 模型选择验证集：TonyPi 完整 `capture-20260914-091540`，35 张人工标注。
- 最终人工测试集：TonyPi 65 张，模型选择期间不使用。

准备工具为 `tools/prepare_yolo_v3_dataset.py`。它会产出可复现 manifest、逐帧审计 JSON
和 4x4 联系表；本轮所有接受的 iPhone 训练标签均已目视审查。

## 训练结果

v3 从 v1 权重微调。验证集在第 2 个 epoch 达到最佳结果，因此最终模型从 v1 重新开始，
在全部训练数据上训练 2 个 epoch。自动选择阈值为 0.1899，部署时应使用约 0.19，
而不是继承 0.25；继续降低阈值会在强运动模糊时出现错误大框。

| 模型 | TonyPi TP / FP / FN | Precision | Recall | F1 | 正样本平均 IoU |
|---|---:|---:|---:|---:|---:|
| v1 | 50 / 1 / 2 | 98.0% | 96.2% | 97.1% | 0.863 |
| v3 | 50 / 0 / 2 | 100.0% | 96.2% | 98.0% | 0.861 |

在未训练的 iPhone session 的 56 张可靠正样本上，v3 在阈值 0.1899 下保持 56/56
（阈值 0.25 时为 54/56），相对教师框平均 IoU 为 0.908。v3 还识别出 v1 漏掉的底部大幅裁切运动帧
`...-0000000443.jpg`（v1 0.029，v3 0.528）。不过极强运动模糊仍有漏检，
所以不能把伪标注留出集当作完整精度结论。

# LAB/SVM/ROI 与 feature-v2 并行实验

后续的近期目标恢复优化见[恢复对照报告](hybrid-recovery-20260914.md)。本文记录首次实验，
其中旧混合行为可通过 `recent_hit_recovery_seconds=0, reuse_frame_scores=False` 重现。

结论：优先继续 LAB+SVM v1+ROI 路线；本次删除分位数的 feature-v2 不推荐替换 v1。
混合方案在简单接近段保持连续识别且明显减少计算，但复杂段仍有恢复间隔造成的漏帧。
本次交付为离线实验，未启用混合检测器作为 GUI/自主控制默认，也未部署或连接机器人。

## 方法和复现条件

并行开发、顺序计时。五种方法在同一进程逐帧执行，每帧轮换顺序；OpenCV 5.0.0、
单线程、640×480，无 profiler，计时只包含 process，不含解码、统计及保存图片。
两段共 2,240 帧全部参与回放。初始化先预热，随后使用全新检测器重置时序状态。
混合恢复调度使用帧序号/10 秒的模拟采集时间，实际采集时间戳未提供。
只有 PC 数据，不能直接当作 Orange Pi 帧率。当前本机基线与前次有波动；仅做本轮
同条件对照，不将前次 20 ms 和本轮时延拼接计算加速比。

- LAB：当前原有检测器。
- SVM v1：原 406 维权重，2,349 字节，未重新训练或覆盖。
- SVM v2：仅去掉 18 个颜色分位数，388 维；HOG、均值/标准差、LAB网格、几何均保留。
  固定原来的 train/test、seed=20260914、C=1、threshold=0，224 正/3339 负训练裁剪，
  662 轮收敛，权重 2,296 字节。没有根据测试结果调整阈值。
- Hybrid v1/v2：LAB 放宽几何门槛后按面积与圆度排名，最多 3 个框进入对应 SVM；
  跟踪时优先在 3 倍球框 ROI 找候选，每 0.5 秒刷新全图 LAB；ROI 失败同帧尝试
  全图 LAB；全部失败后每 0.3 秒执行一次原有宽松 LAB/HSV 提议+SVM。
  单次快速阶段最多 3 个框；ROI失败后全图阶段可以再处理 3 个。宽松恢复最多 128 个。

ROI 框映射回完整处理图提取特征，保证上下文和图像边缘特征含义不变。
人工 ROI 边界截断的候选会转全图重试；摄像头底边截断球仍允许识别。
丢失帧不重复利用旧阳性结果，不累计虚假的连续确认；配置、图像尺寸或时间倒退重置状态。
SEARCH 由“未跟踪/检测丢失”模拟，目前未接入控制器状态或真实摄像头调度。

093059 中，Hybrid v1 为 454 帧 ROI、114 帧全图 LAB，无需宽松恢复；平均每帧分类
1.403 个候选。568 帧连续输出，566 帧通过控制确认，前两帧为正常的三帧确认等待。

反而略高于 Hybrid v1 的 2.49 ms，虽然中位数较低。

091540 中，Hybrid v1 平均分类 11.398 个候选，451 帧 ROI、136 帧全图 LAB命中、
18 帧宽松 SVM 命中，358 帧宽松搜索无结果，709 帧快速搜索无结果且尚在恢复冷却中。
控制确认帧数从 v1 的 575 变成 568。

## 人工标注定位（IoU≥0.5）

52 个原有稀疏标注：29 train/dev（15有球/14无球），23 test（13有球/10无球）。
原有测试集已经在此前评估中查看过，不能称为新独立泛化验证。两个采集来自同一场地，
第一段包含重复帧，第二段有大量静止相邻帧，整段候选统计不能替代独立标注。

| 方法 | 连续回放 dev 正确/15 | 连续回放 test 正确/13 | test 无球误检/10 | test 正帧平均 IoU |
|---|---:|---:|---:|---:|
| SVM v1 | 14 | 13 | 0 | 0.846 |
| SVM v2 | 14 | 11 | 0 | 0.714 |
| Hybrid v1 | 14 | 13 | 0 | 0.837 |
| Hybrid v2 | 13 | 12 | 0 | 0.768 |

每个标注单独启动的新检测器结果：前三种与连续回放相同；Hybrid v2 的 dev
恢复为14/15（连续状态下1543帧被冷却跳过），test仍12/13。
定位不达标同时算 FP/FN；此表的“无球误检”仅计算无球标注帧，不能与全部 FP混同。
LAB 返回圆而不是框，本次没有用外接正方形冒充 LAB 真正预测框算 IoU。

## 具体回退与改善

- v2 测试标注漏检为 093059 的102、117帧。两帧宽松候选的最佳 IoU分别为
  0.879、0.851，但分类分数未通过0阈值，说明分位数特征在当前小样本模型中有用。
- v2 整段漏检：102、113、114、115、117、120、129、210、211、212、214帧。
- 093059 的116帧：v1/v2都优先选球内部13×19小框，半径9.5px；Hybrid v1输出
  [236,305,293,359]、半径28.5px，目视贴合完整球；Hybrid v2在此帧无输出。
  此改善来自候选路径变化，并未对116帧添加特判或训练。
- 091540 中，Hybrid v1 相比 v1 有11帧丢失、1帧新增，净少10帧。丢失为
  1471、1474、1487、1538、1544、1545、1547、1550、1560、1582、1635帧，
  均是快速检测失败且宽松搜索仍在0.3秒冷却中。包括近距离真实球，不能声称零回退。
  尚未对这些帧全部新增真值，少量小框可能原本就是错误候选，不能将11直接当作额外FN。

因此保留 Hybrid v1 为下一步候选；接入运动前应专门验证近距离、晃动、恢复等待与
三帧确认之间的关系。单纯缩短冷却会增加计算；可以另做“近期有目标时优先恢复”的
实验，但本次不在已查看的测试结果上继续挑参数。

## 文件与复现

从项目根目录运行：

```sh
python tools/train_edge_detector.py --annotations data/red-ball-20260914/annotations.json --feature-version 2 --output artifacts/edge-experiments-20260914/feature-v2
python tools/compare_edge_experiments.py --v1 artifacts/edge-model-20260914/red_ball_svm.npz --v2 artifacts/edge-experiments-20260914/feature-v2/red_ball_svm.npz --out artifacts/edge-experiments-20260914/comparison --threads 1
```

- `src/hcirobot/hybrid_detector.py`：实验混合检测器；使用原v1模型，无需重训。
- `src/hcirobot/edge_detector.py`：自动读取权重中的特征版本，默认v1保留；v2可通过现有模型路径显式选择。
- `artifacts/edge-experiments-20260914/feature-v2/`：新模型和训练/标注报告。
- `artifacts/edge-experiments-20260914/comparison/summary.json`：全部指标、条件、模型哈希。
- 同目录 `capture-*.json`：逐帧时延、框、半径、控制确认、路由和分类数量。
- 同目录 `annotated.json`：连续与单图模式标注对照；`capture-*-comparison.jpg`为五路可视化。

验证：feature测试12项、hybrid测试7项分别通过；集中检测器/CLI/GUI模型路径定向回归
通过（有1项GUI测试跳过）。修改代码Ruff通过。没有为这次独立实验运行耗时的全项目回归。

# LAB + SVM v1 + ROI：保留版本的优化实验

优先实测 `hybrid-v1-fast`。它保留原 v1 权重、406 维特征和分位数；两段共 2,240 帧的
顶部框、分数、候选/控制状态及搜索路线与恢复优化版完全一致，复杂段平均耗时下降约 28%。
`hybrid-v1-geometry` 可作为近距离大球实验对照。困难负样本权重改善背景误框，但损失了一张
球帽诊断图，保留作对照，暂不推荐直接替换。

本次完成离线实验和 GUI/CLI 版本选择，未进行机器人实测。所有性能数字来自本机，
不代表 Orange Pi。两段采集已多次查看、用于开发，不能证明跨场景泛化。

## 版本保留与切换

目录：`artifacts/edge-versions-20260914/`。`manifest.json` 收录 9 个策略配置；
`models/` 保留 3 份独立权重。每个 `profiles/*.json` 指定相对权重路径、SHA256、
完整检测参数及策略开关，加载时校验权重。原路径下的 v1/v2 权重也没有改动。

| JSON 文件名 | 权重 | 策略及用途 |
|---|---|---|
| `svm-v1.json` | v1，2,349 B | 原全图 SVM 基线 |
| `svm-feature-v2.json` | feature-v2，2,296 B | 去除分位数的旧实验 |
| `hybrid-v1-legacy.json` | v1 | 最初 LAB + SVM + ROI，关闭近期恢复和缓存 |
| `hybrid-feature-v2.json` | feature-v2 | 最初混合 feature-v2 对照 |
| `hybrid-v1-recovery.json` | v1 | 上轮 300ms 近期恢复 + 同帧缓存 |
| `hybrid-v1-fast.json` | v1 | 上轮策略 + 候选去重/批量特征提速；优先实测 |
| `hybrid-hn-v1-fast.json` | hn-v1，2,354 B | 提速 + 困难负样本权重；有球帽回退 |
| `hybrid-v1-geometry.json` | v1 | 提速 + 大球/底边球帽候选 + 包含框选择；实验 |
| `hybrid-hn-v1-geometry.json` | hn-v1 | 困难负样本与几何策略合并；实验 |

GUI：勾选“使用端侧模型 / 实验版本”，点击“选择”，打开对应 JSON，再启动会话。
启动时日志显示版本 ID，调优面板同步实际版本参数。切换版本需要结束并重新开始会话。
JSON 中固定的是检测参数；控制器、视频和机器人连接仍使用会话配置。
手工点击“应用参数”会修改当前运行参数，做版本对照时应记录这类改动。
直接选择 `.npz` 仍表示全图 SVM，并使用当前配置文件中的检测参数。

CLI 示例（在项目根目录）：

```sh
python -m hcirobot --config config.toml --edge-model artifacts/edge-versions-20260914/profiles/hybrid-v1-fast.json --check-config
```

训练工具现在拒绝覆盖已有模型/报告；回放工具拒绝写入非空报告目录。
`source/`、`source-sha256.json` 保存检测器、训练/对比脚本及标注快照；
`training-reports/` 保存三次训练报告。新增优化不覆盖旧版权重。

## 三项实验的具体变化

**提速**：宽松候选按照原顺序做向量化 IoU 去重，仍保持最多 128 框。
4 个及以上待分类框使用批量颜色统计、分位数和 HOG 归一化；逐 patch 的 Sobel 保留边界
语义。1–3 框仍使用原特征提取，避免常规 LAB/ROI 路径支付批处理开销。
新后端通过显式开关启用，旧版默认行为可重现。没有降低分辨率或删除特征。

**困难负样本**：在原 29 张训练图后加入第一段 1487、1582、1635 三张人工确认无球的图。
224 个正样本裁剪保持不变，负样本裁剪从 3339 增至 3824；仍训练 feature-v1、阈值 0。
模型 911 轮收敛，训练裁剪准确率 100%（这不是实测准确率）。
1470、1471 底部仍有球帽，没有被误标为整帧负样本。

**几何策略**：候选最大框面积从画面 35% 放宽到 65%；真正接触图像底边的候选允许
宽高比上限 12，其余仍为 5；人工 ROI 裁切边缘仍触发全图恢复。
宽松搜索后，在已经通过 SVM 的框中，允许覆盖当前小框至少 90%、面积为其 1.4–8 倍的
最大框替代内部小框。阈值为本轮固定的实验设置，没有进行网格搜索。
它输出可见区域的框，不外推画面外完整球体或真实距离。

## 同条件全量回放

OpenCV 5.0.0 单线程，640×480，逐帧轮换各版本执行顺序，合成采集时钟 10Hz。
计时不含磁盘解码、日志和写图；没有并行跑其他训练/测试。系统负载仍可能导致波动，
应比较本表同一轮数据，不能直接与之前另一轮耗时相减。

第一段 `091540`，1,672 帧：

| 版本 | 候选帧 | 控制确认帧 | 候选连续段 | 平均 ms | P95 ms |
|---|---:|---:|---:|---:|---:|
| recovery | 610 | 578 | 18 | 14.13 | 63.98 |
| fast | 610 | 578 | 18 | 10.23 | 39.60 |
| hn-fast | 608 | 579 | 15 | 10.38 | 39.13 |
| geometry | 611 | 581 | 17 | 10.10 | 39.05 |
| hn-geometry | 609 | 582 | 14 | 10.22 | 39.08 |

相同宽松搜索帧的平均耗时：46.02 → 29.42ms，下降约 36%；复杂段整体 P95 下降约 38%。
中位数 5.59 → 5.54ms，常规路径几乎不变。控制确认数量仅表示检测器输出，
不代表机器人成功率，也不等于正确识别帧数。

第二段 `093059`，568 帧：五个版本均为 568 候选、566 控制确认、1 个连续段。
平均分别 2.96 / 3.05 / 3.02 / 3.03 / 3.19ms；fast 与 recovery 走相同路线，
没有宽松搜索，因此这里没有测得提速收益。hn 版本有 1 帧改走宽松搜索，定位略有变化。

原有稀疏标注上，五个版本均保持：训练/开发有球 14/15、无球 0/14 误检；
测试有球 13/13、无球 0/10 误检，测试有球平均 IoU 0.8365。
开发集仍有 1 张定位不达标，计入 FP 和 FN，不能说所有标注都通过。

## 定位收益与回退

新增 9 张定向诊断图（6 有球、3 无球），框为可见球区域的近似人工标注：

- 1538：geometry 的 IoU 从 0.781 提升到 0.881。
- 1544：geometry 的 IoU 从 0.633 提升到 0.911。
- 1474：fast 能识别底边球帽，IoU 0.860；hn-fast 与 hn-geometry 都漏检。
- 1470、1471：所有版本都还没正确找回球帽；hn 去掉了原背景误框，但没有找回真球。
- 独立启动检测 1488、1622、1661 三张无球图：v1 误检 3 张，hn 为 0。
  **1488 与新训练图 1487 完全相同**，必须剔除这个重复项才是非重复诊断：2 张误检 → 0 张。
- 1544 也与原训练图 1543 完全相同。其大球定位改善属于训练场景诊断，不能计作泛化收益。
- 1548、1550 的 geometry 框会扩到右图像边界，包含额外背景，尺寸仍可能偏大。
  SVM 的正分数没有保证框边界正确；几何版的半径和到达距离应单独对照。

全部 9 张诊断在独立启动时，v1 有球正确定位 4/6，hn 为 3/6；
geometry 改善框质量，但没有增加这 6 张的通过数量。完整时序会跳过部分背景帧的宽松搜索，
因此时序回放无球误检较少；不能用冷却跳过代替分类质量评估。
这些诊断是已知问题及邻近帧，含上述完全重复图，**不是独立测试集**。

## Orange Pi 实测入口

使用当前项目代码，把完整版本目录复制到板上，保留 `profiles/` 与 `models/` 的相对位置。
先用同一段采集比较 recovery / fast，再对比 geometry / hn，输入顺序和 FPS 保持一致。
每次使用新输出路径；工具只跑识别，不连接机器人。

```sh
python tools/benchmark_edge_detector.py --frames artifacts/captures/capture-20260914-091540 --edge-model artifacts/edge-versions-20260914/profiles/hybrid-v1-fast.json --out artifacts/orangepi-fast-run1.json --limit 1672 --threads 1 --fps 10
```

该工具默认顺序处理前 N 帧，混合策略按原帧号/FPS 调度，预热后清空跟踪状态；
`--sampling uniform` 会跳过中间跟踪观测，不能当作连续性实验。
报告含版本配置、实际权重大小/哈希、处理尺寸、板型号、均值/P50/P95、进程峰值内存。
权重约 2.3KB，不等于 Python/OpenCV 运行内存。

全版本对比工具支持任意 JSON 列表，例如：

```sh
python tools/compare_edge_experiments.py --profiles artifacts/edge-versions-20260914/profiles/hybrid-v1-recovery.json artifacts/edge-versions-20260914/profiles/hybrid-v1-fast.json --out artifacts/field-replay-run1 --threads 1 --fps 10
```
